Homa · peer-to-peer terminal chat

github.com/Serajian/homa

Two people exchange one address and talk directly over WireGuard through NAT, on Tailscale's data plane with the control plane removed; a relay only helps when no direct path exists. No accounts and no server keeping messages. Peers are identified by key rather than by the name they announce, and file transfers are checked against a digest. Released as v0.1.0 through Homebrew and a signed apt repository.

Go · WireGuard · tailcat · GoReleaser · GitHub Actions

Srosha · asynchronous notification service

github.com/Serajian/srosha

A client submits once over gRPC and is acknowledged immediately; a separate dispatcher delivers across eight channels (Email, Telegram, Bale, WhatsApp, Matrix, Gotify, FCM, APNs) at least once, with per-channel retry and HMAC-signed status webhooks. Intake and delivery are separate binaries, so a broken provider never stops a request being accepted. Hexagonal core with the dependency rule checked on every commit, and a Go SDK that stays one toolchain version behind the service.

Go · gRPC · PostgreSQL · NATS JetStream · Docker
